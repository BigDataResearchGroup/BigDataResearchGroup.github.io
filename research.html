Current Projects

Multi-perspective patient representation learning for disease prediction on electronic health records. Knowledge and Information Systems

This project proposes a framework called multi-perspective patient representation extractor for disease prediction based on EHR. The goal is to effectively detect the useful information (e.g., long-term and short-term trends, variations, and correlations between trends and variations) of dynamic features for patient representation.

Disease prediction Patient representation Electronic health records

A survey on personalized document-level sentiment analysis

This project designs an architecture called User Correlation Mining for personalized document-level sentiment analysis. This project is the first to adopt user correlation for personalized document-level analysis.

Document-level sentiment analysis Data mining Correlation analysis

ST-RLNet: Spatio-Temporal Representation Learning for Multi-Step Traffic Flow Prediction

This project proposes a deep spatio-temporal representation learning network for multi-step traffic flow prediction. The objective is to effectively generate the traffic data representation for each step of prediction by better capturing the complex correlations (i.e., spatial, temporal and spatio-temporal correlations) among traffic data.

Multi-step prediction Representation learning Spatio-temporal correlation
